# 泡泡桌宠

> [English Documentation](README.en.md)

泡泡桌宠是一款常驻屏幕角落的透明桌面陪伴挂件。你不必把它当成游戏——它陪你敲键盘干活：两只小泡泡龙跟随你的按键同步转滚轮、按空格朝滚轮方向吐一个泡泡，泡泡飞远后自动破裂回收，不会累积成负担。

基于 **Electron + PixiJS + uiohook-napi** 构建（PixiJS 负责全部渲染，无需 DOM 动画开销）。macOS 为开发原型机，Windows 为正式发布主战场。

## 功能特性

- 透明悬浮挂件，常驻屏幕角落，可拖动并记忆位置
- 全局键盘监听：

  | 你的操作 | 挂件反应 |
  | --- | --- |
  | 敲键盘左半区任意键（G/T/V 及左侧，含 1–5） | 滚轮向左转，左龙走踏，播放转动音效 |
  | 敲键盘右半区任意键（H/Y/B 及右侧，含 6–0） | 滚轮向右转，右龙走踏，播放转动音效 |
  | 按空格 | 沿滚轮角度吐出一个泡泡（发射音效），发射后指针自动回中 |
  | 方向键 ← / → | 滚轮左转 / 右转（仅此两个特殊键生效） |
  | 任意字母 / 数字键 | 发射球中心渐隐显示所按字符（白字黑边带阴影） |
  | `Cmd/Ctrl + Shift + B` | 显示 / 隐藏（全局快捷键） |

- 泡泡触顶自动破裂回收，不会累积
- 状态栏托盘菜单：显示 / 隐藏、始终置顶、音效开关、转动 / 发射音效独立音量档位（10%–100%，持久化）、恢复 / 取消触点、统计面板、开机自启动、退出；未授权时提供“去授权”入口
- 统计面板：近 7 天逐日打星星得分，以及最近 7 天每个按键（26 个字母、数字 0–9、左右方向键）的点击次数

键盘监听是**全局**的：窗口不聚焦、你在别的应用里打字，滚轮也会跟着转。

## 快速开始

环境要求：Node.js 与 pnpm；macOS 首次运行需要“辅助功能”授权（详见下文）。

```bash
pnpm install    # 首次安装（postinstall 会自动生成 vendor 运行时）
pnpm start      # 启动挂件（pnpm dev 等同）
```

工程检查与打包：

```bash
pnpm verify       # 语法检查 + 自动化测试 + 皮肤物料校验
pnpm run dist     # 构建安装包
```

自动化测试使用 Node 内置测试运行器，无额外开发依赖。

## macOS 首次运行：授权

全局键盘监听需要“辅助功能”权限。未授权时托盘菜单会出现“去授权”入口，点击弹出系统授权引导（或前往 系统设置 → 隐私与安全性 → 辅助功能 勾选本应用）。**授权后需要重启应用生效**。

未授权时的兜底行为：仅当挂件窗口聚焦时响应键盘。

Windows 无需授权。

## 打包（macOS）

```bash
pnpm run dist   # 输出 dist/ 下的 dmg 与 zip（Apple Silicon，未签名）
```

注意事项：

- 打包后是独立 App，需在 系统设置 → 隐私与安全性 → 辅助功能 中单独授权（与开发时 Electron 的授权不共享），授权后重启生效。
- 未签名应用在其他 Mac 首次打开会被 Gatekeeper 拦截，右键 → 打开即可。
- 图标使用 AI 生成的原创 logo；状态栏图标为系统模板图（自动适配深浅色）。

## 皮肤机制（JSON 驱动）

角色不再是固定贴图，而是用 `skins/<id>/character.json` 物料驱动。物料声明 `type: "text" | "image"`，共用同一套动画编排（`fire` / `walk` / `idle` 三状态的整体形变）：

- **text 物料**：以文字作为角色，样式由 `style` 定义（字号、加粗、填充、描边、投影）与系统字体栈驱动，不打包任何字体文件、零字体授权负担。
- **image 物料**：每个状态一张静态 PNG，按状态切换贴图。
- 动画编排支持缩放、倾斜、位移动画（`sine` / `pulse` 两种波型），新增角色只需放一份物料并在 `skins/index.mjs` 注册，零代码改动画逻辑。
- `pnpm validate:character` 会全量校验物料字段合法性，已纳入 `pnpm verify`。

扩展新皮肤是后续商业化（免费本体 + 皮肤）的基础能力，资源目录沿用 `skins/<id>/` 约定。

## 技术栈

- **Electron**：桌面壳与主进程能力（全局键盘、托盘、IPC、全局快捷键）
- **PixiJS**：渲染进程场景与每帧编排
- **uiohook-napi**：N-API 全局键盘监听（免 Electron 重编译）

## 目录结构

```text
main.js                    主进程入口与桌面能力编排
├── main/keyboard-hook.js  全局键盘捕获：只发布 key:down / key:up 事实
├── main/window-state.js   窗口位置持久化与显示器校验
├── main/score-stats.js    打星星得分按天持久化与报告
└── main/desktop-ipc.js    IPC 信任边界与窗口拖动

preload.js                 最小化渲染进程 API
src/game.js                PixiJS 场景、输入与每帧编排
├── src/game/domain.mjs    无运行时依赖的纯领域规则
└── src/features/          自治玩法功能（星星、计分、事件契约）
```
